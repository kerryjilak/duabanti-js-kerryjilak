# Week 02 Reflection

## What I built
I built a small JavaScript converter in week02-converter.js. It includes three functions:

- cedisToDollars(cedis): converts Ghanaian cedis to US dollars using the rate 0.086 and prints the result with two decimal places.
- kmToMiles(km): converts kilometers to miles using the factor 0.621371 and prints the result with two decimal places.
- celsiusToFahrenheit(celsius): converts Celsius to Fahrenheit using the formula (celsius * 9/5) + 32 and prints the result with two decimal places.

This was a simple practice project to help me understand JavaScript functions, math operations, and readable terminal output.

## What got me stuck
The main thing that slowed me down was making sure each conversion formula was correct and that the output was formatted the way I wanted. I also had to be careful with the conversion rate and rounding values using toFixed(2), so the results looked clean and consistent in the console.
